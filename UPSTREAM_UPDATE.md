# Обновление форка до v0.1.17.15

Оригинал: [sidor0912/FunPayCardinal](https://github.com/sidor0912/FunPayCardinal).
Зафиксированная версия: [c09dd13, 24 сентября 2026](https://github.com/sidor0912/FunPayCardinal/commit/c09dd13be25072bb3d5cdbba33d1e0d70e477710).
Исходное состояние форка: `3e93158`.

Форк ранее обновлялся выборочно: новый код API соседствовал с неполными
моделями данных и старой логикой обработчиков. Надпись `0.1.16.2` при запуске
не отражала фактически перенесённые изменения. Обновление объединяет историю
оригинала с историей форка, сохраняя его доработки.

## Изменения, влияющие на работу

| Область | Изменение | Практический эффект |
| --- | --- | --- |
| Автовыдача | При нескольких совпадениях выбирается самое длинное подходящее название; учитывается сторона лота | Например, `Game Premium` выбирается раньше `Game`, если оба подходят. Приоритет точного совпадения сохранён |
| Товарные файлы | Чтение, выдача, добавление и загрузка товаров используют общий замок на файл | Параллельные заказы не должны получать одну и ту же строку товара |
| Восстановление и отключение лотов | Обновление профилей и состояния лотов выполняется последовательно в одном фоновом потоке | Изменился порядок обновления данных после продажи |
| Автоподнятие | Используется возвращаемое FunPay время ожидания; устранён повторный запрос после успешного поднятия | Изменяется расписание следующего поднятия и уменьшается количество запросов |
| Сообщения | Удаляются невидимые окончания; удалённые администраторами чаты пропускаются; используется общий форматтер Telegram | Исправляются обработка истории и отображение сообщений |
| Заказы и плагины | Восстановлены отсутствующие классы `Server`, `Side`, `Wallet` и новые свойства; ошибки регистрации обработчиков отключают проблемный плагин | Устраняются несовпадения между `account.py` и моделями данных. Ошибка одного плагина не прерывает регистрацию остальных |
| Список продаж | Проверяется, что FunPay действительно вернул страницу продаж | Посторонняя страница не принимается за пустой список заказов |
| Прокси | `socks5` нормализуется в `socks5h` | DNS-запросы выполняются через прокси |
| Linux-установщик | Добавлен приоритет IPv4 в `/etc/gai.conf` | Настройка всей системы изменится только при запуске установщика. При обновлении исходников установщик не запускался |

Также перенесены обновления логирования, управления автовыдачей через Telegram
и файлы для запуска через Docker.

## Сохранённые доработки форка

- Удалены объявления, реклама, донат и кнопка покупки плагина; `announcements.py`
  и `.github/FUNDING.yml` остаются удалёнными.
- Бот не меняет своё имя и описание в Telegram. Нет требования начинать
  username с `funpay`; правила пароля сохранены из форка.
- Ссылки интерфейса, установщика и службы ведут на `chtowsappx/FunPayCardinal`.
- Сохранены дополнительные поля профиля: `activation`, `reg_data`, `support`,
  `arbitration`, `moderation`, `rating`, `reviews`, `lots_count` и их заполнение.
- Сохранены интерфейс конструктора `Order` из форка, поля `price`, `description`,
  `buyer_params`, `html`, метод `get_buyer_param`, необязательная локаль.
  Добавлено свойство `payment_msg`; `character_name` использует имя игрока,
  если отдельный параметр покупателя отсутствует.
- Сохранены значения по умолчанию `PluginData.pinned`, исправленная миграция
  старых прокси, обработка сохранённых прокси и функция `LINKS_KB`.
- Сохранены имена старых обработчиков профиля для плагинов, импортирующих их напрямую.
- Команды обновления из оригинала не возвращены в панель Telegram, чтобы они
  не перезаписывали доработки форка.
- Сохранены настройки первичного запуска, включая стандартный водяной знак;
  миграция из оригинала, автоматически заменяющая его, не добавлена.

## Проверка и ограничения

Проверки запускаются без подключения к аккаунтам:

```sh
python -m unittest discover -s tests -v
```

Все 14 проверок прошли. Проверены выбор автовыдачи, совпадение сервера и стороны, заполнение профиля,
совместимость заказа, товарные файлы при параллельной выдаче, миграция прокси,
невидимые окончания сообщений, регистрация обработчиков Telegram, отсутствие
рекламы и защита списка продаж от неверной страницы.

Дополнительно проверены импорт основных модулей, синтаксис Python и установщика,
целостность зависимостей и отсутствие незавершённых конфликтов слияния.

Бот и установщик не запускались. Проверка с реальными аккаунтами FunPay/Telegram
и установленными сторонними плагинами не выполнялась: их настройки и файлы
отсутствуют в этом checkout. Существующие предупреждения Python о строковых
escape-последовательностях и устаревших вызовах BeautifulSoup не мешают проверкам.

Предыдущее состояние кода сохранено в ветке `codex/backup-before-0-1-17-15`.
